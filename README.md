📌 وصف المشروع

منصة نَبْرة هي نظام دردشة تفاعلي (Chatbot) متخصص في اللهجات السعودية.
يتيح للمستخدم كتابة كلمة أو جملة، ويقوم النظام بإظهار مرادفاتها باللهجات المختلفة بالإضافة إلى المعنى بالفصحى.
كما يمكن للنظام الاستعانة بالذكاء الاصطناعي (Gemini) لإعطاء شرح مخصّص بلهجة يحددها المستخدم.

المشروع يعتمد على:

Flask (Back-end)
HTML / CSS / JavaScript (Front-end)
JSON Dictionary لقاعدة بيانات الكلمات
Gemini API لتوليد الشروحات عند الحاجة

🧠 كيف يعمل النظام؟ (Flow)
1️⃣ المستخدم يكتب كلمة

⇒ النظام ينظّف النص ويستخرج الكلمة الأساسية
⇒ يبحث عنها في dictionary.json

2️⃣ إذا وجد كلمة

⇒ يظهر معناها باللهجات المختلفة

3️⃣ إذا لم يجد

⇒ يسأل المستخدم إن كان يريد استخدام Gemini لتوضيح المعنى

4️⃣ إذا وافق المستخدم

⇒ يختار اللهجة من قائمة مرقمة
⇒ يتم إرسال الطلب إلى API
⇒ يعرض الرد باللهجة المطلوبة
